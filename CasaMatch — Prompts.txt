# CasaMatch — Prompts útiles

## Prompt para crear demo HTML

Actúa como diseñador UX/UI senior y frontend developer experto.

Crea una demo visual navegable en un solo archivo HTML para CasaMatch, una app inmobiliaria moderna inspirada en Airbnb, Tinder y TikTok.

CasaMatch permite descubrir casas, departamentos, terrenos e inversiones inmobiliarias compatibles con el estilo de vida, presupuesto y preferencias del usuario.

Requisitos:
- Todo en un solo archivo HTML.
- CSS dentro de `<style>`.
- JavaScript dentro de `<script>`.
- Sin backend real.
- Datos simulados.
- Diseño mobile-first.
- Estilo premium, moderno, limpio y amigable.
- Inspiración visual: Airbnb, Tinder, TikTok, Apple y apps fintech.
- Cards grandes, bordes redondeados, sombras suaves y animaciones.
- Paleta: blanco, arena, gris claro, negro suave, coral/terracota o verde oliva.
- Tipografía moderna tipo Inter o similar.
- Debe verse como producto real, no como wireframe.

Incluir pantallas:
1. Landing de presentación.
2. Onboarding de preferencias.
3. Feed tipo swipe.
4. Detalle de propiedad.
5. Reels inmobiliarios.
6. Panel para asesores/inmobiliarias.
7. Simulador hipotecario.
8. Captura de interesados.

Funciones:
- Navegación simulada.
- Cards dinámicas.
- Like/dislike/guardar.
- Mensajes visuales.
- Simulador hipotecario funcional.
- Generador IA simulado para descripciones.
- Formulario de contacto con mensaje de éxito.

Propiedades ficticias:
- Casa moderna en Querétaro.
- Departamento en CDMX.
- Casa familiar en Celaya.
- Terreno de inversión en León.
- Departamento pet friendly en Guadalajara.

Entrega únicamente el código completo listo para copiar como index.html.
